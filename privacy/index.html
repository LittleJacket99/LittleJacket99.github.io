Privacy Policy

Last updated: September 18, 2026 · Applies to ED Hotspots Finder - Rings & Planets v1.0.1 and this website.

ED Hotspots Finder - Rings & Planets is an open-source Windows companion for Elite Dangerous maintained by LittleJacket99. It can query public/community game-data services, save local application settings, export results on request and optionally synchronize compatible RhinoSpotter bookmarks with Community Deposits.

Local application settings

The application stores its settings locally in:

%APPDATA%\HotspotsFinder\config.json

This can include interface preferences, startup filter defaults, the configured RhinoSpotter data path and related application options. The current app does not use Google OAuth or require a Google account.

Spansh

ED Hotspots Finder uses Spansh to resolve Elite Dangerous system names and retrieve system/body data. Search inputs relevant to those requests, such as system names and applicable search criteria, are sent to Spansh when required to perform the search.

Community Deposits

Community Deposits is an online community database of player-reported planetary surface deposits. When Community Deposits is enabled during a search, the app sends the relevant system names to the Community Deposits service so that matching reports can be returned.

When you explicitly start a RhinoSpotter synchronization, compatible bookmark data is prepared and sent to the Community Deposits service. This can include game-location fields such as system, body, material, coordinates and compatible report metadata recorded by RhinoSpotter. Synchronization is user-triggered; the app does not continuously upload RhinoSpotter data in the background.

RhinoSpotter local data

RhinoSpotter is an independent EDMC plugin developed by Fumlop. Current RhinoSpotter releases store bookmarks in a local SQLite database, normally located at:

%LOCALAPPDATA%\RhinoSpotter\db\rhinospotter.db

ED Hotspots Finder opens that database in read-only mode for detection and synchronization. It does not modify the RhinoSpotter database. Legacy JSON card folders are supported as a fallback.

Exports

CSV and XLSX exports are created only when you choose to export results. Those files are written locally to the destination you select and are not automatically uploaded to the maintainer.

Telemetry, advertising and accounts

The application does not require an ED Hotspots Finder account and does not include advertising. The published project does not implement developer analytics or automatic telemetry reporting. Normal network services may still receive standard connection information such as your IP address when you use them.

This website

This static GitHub Pages website uses no analytics scripts, advertising, forms or application cookies. Images are loaded from the project's public GitHub repository. GitHub Pages and GitHub may process normal hosting and request data under the GitHub Privacy Statement.

Third-party services and projects

Spansh, GitHub and RhinoSpotter are independent services/projects with their own policies and maintainers. ED Hotspots Finder is not affiliated with Frontier Developments, Spansh or RhinoSpotter.

Contact and changes

For privacy questions or to report a discrepancy, use the project's GitHub issues. Issues are public, so do not include private files, credentials or other sensitive information. Material changes to the app's data handling will be reflected on this page.

Privacy Policy

Last updated: September 20, 2026 · Applies to ED Hotspots Finder - Rings & Planets v1.0.2, Hotspots Finder EDMC Plugin v1.0.2 and this website.

ED Hotspots Finder - Rings & Planets and Hotspots Finder EDMC Plugin are open-source Elite Dangerous companion tools maintained by LittleJacket99. They can query public/community game-data services, store local configuration and optionally synchronize compatible RhinoSpotter bookmarks with Community Deposits.

Local configuration

The desktop Finder stores its settings locally in:

%APPDATA%\HotspotsFinder\config.json

This can include interface preferences, startup filter defaults, RhinoSpotter options and related application settings. The Finder does not require a Google account or Google OAuth.

The EDMC Plugin stores its own plugin configuration through EDMarketConnector, including information needed for features such as the configured Finder executable and tracker position.

Spansh

ED Hotspots Finder uses Spansh to resolve Elite Dangerous system names and retrieve system/body data. Search inputs relevant to those requests, such as system names and applicable search criteria, are sent to Spansh when required to perform a search.

Community Deposits

Community Deposits is an online database of player-reported planetary surface deposits used by both the Finder and EDMC Plugin.

When Community Deposits is searched, the relevant system name or names are sent to the Community Deposits service so matching records can be returned.

When you explicitly start RhinoSpotter synchronization, compatible bookmark data is prepared and sent to Community Deposits. Depending on the bookmark, this can include game-location and deposit information such as system, body, Location, material, Rigs, Amount, Density, coordinates, heading, body metadata and depletion information.

Synchronization is user-triggered. Neither the Finder nor the EDMC Plugin continuously uploads RhinoSpotter bookmarks in the background.

RhinoSpotter local data

RhinoSpotter is an independent EDMC plugin developed by Fumlop. RhinoSpotter 5.1+ exposes a documented external API at:

%LOCALAPPDATA%\EDMarketConnector\plugins\RhinoSpotter\rs_api.py

Both ED Hotspots Finder and the EDMC Plugin can read compatible bookmark information through that API. The EDMC Plugin uses rs_api.py only.

For compatibility with older RhinoSpotter installations, the desktop Finder can also read the local SQLite bookmark database in read-only mode and legacy JSON card folders. It does not modify RhinoSpotter's database.

Elite Dangerous / EDMarketConnector status data

The EDMC Plugin uses the current Elite Dangerous system reported by EDMarketConnector for current-system Community Deposits lookup. When you start tracking a selected deposit, it uses live status data exposed through EDMarketConnector / Elite Dangerous Status.json to calculate navigation information such as distance, bearing and relative direction.

This navigation status is used locally for the tracker and is not described here as an automatic Community Deposits upload.

Exports

CSV and XLSX exports are created only when you choose to export Finder results. Those files are written locally to the destination you select and are not automatically uploaded to the maintainer.

Update checks

Finder and EDMC Plugin can check the project's public GitHub Releases endpoint for a newer version. A successful check compares the installed version with the latest public release; installation is not performed automatically.

Telemetry, advertising and accounts

The project does not require an ED Hotspots Finder account and does not include advertising. The published tools do not implement developer analytics or automatic telemetry reporting. Normal network services may still receive standard connection information such as your IP address when you use them.

This website

This static GitHub Pages website uses no analytics scripts, advertising, forms or application cookies. Images are loaded from the project's public GitHub repository. GitHub Pages and GitHub may process normal hosting and request data under the GitHub Privacy Statement.

Third-party services and projects

Spansh, GitHub, EDMarketConnector and RhinoSpotter are independent services/projects with their own policies and maintainers. ED Hotspots Finder and Hotspots Finder EDMC Plugin are not affiliated with Frontier Developments, Spansh or RhinoSpotter.

Contact and changes

For privacy questions or to report a discrepancy, use the project's GitHub issues. Issues are public, so do not include private files, credentials or other sensitive information. Material changes to the tools' data handling will be reflected on this page.

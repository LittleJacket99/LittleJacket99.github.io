Hotspots Finder EDMC Plugin

Community Deposits while you are in-game.

Displayed inside EDMC as Hotspots Finder Deposits Companion, the plugin can synchronize RhinoSpotter bookmarks, scan the current system, reopen cached deposit results and navigate to a selected surface deposit.

Results include Body, Location, Material, Rigs, Amount, Density, coordinates, report count and Updated time. The tracker shows the target body, material, RhinoSpotter Location, relative direction and altitude-aware distance.

Community Deposits

A shared database for planetary mining discoveries.

Surface locations are much more useful when they do not stay on one commander's PC. Community Deposits builds a searchable collection of player-reported planetary deposits over time.

Discover→Bookmark→Synchronize→Share→Search

Finder and EDMC Plugin use the same service. The database is community-reported and still growing: missing data does not mean a deposit is absent.

RhinoSpotter integration

Bookmark in-game. Sync when you choose.

RhinoSpotter, developed independently by Fumlop, is an EDMC plugin for recording planetary surface-mining locations while you play.

RhinoSpotter 5.1+ exposes a documented rs_api.py interface. Both the Finder and EDMC Plugin can use compatible bookmarks from that API for Community Deposits synchronization.

The EDMC Plugin uses rs_api.py only. The desktop Finder prefers the same API but keeps read-only SQLite and legacy JSON fallbacks for older RhinoSpotter installations.
